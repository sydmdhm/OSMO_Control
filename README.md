# Osmo Control

一款通过蓝牙（BLE）遥控大疆 Osmo 系列运动相机的 Android 应用，用于替代或补充相机机身按键，在手机上完成连接、状态查看、拍录控制与 GPS 信息注入。

---

## 软件功能

### 1. 设备扫描与连接

- 下拉刷新触发蓝牙扫描，自动列出附近的 Osmo 相机。
- 每台设备显示名称、MAC 地址与信号强度（RSSI）。
- 一键连接 / 断开，连接状态实时显示（未连接 / 已连 / 握手中 / 错误等）。

### 2. 实时状态获取

- 连接后持续接收相机推送的状态，以卡片形式展示：
  - 当前拍摄模式、录制状态、电量
  - 分辨率、帧率、防抖（EIS）
  - 已录时长、剩余容量、可拍张数、可录时长
  - 温度、电源模式

### 3. 操控

- **模式切换**：滑动或点击选择器即可切换拍摄模式（拍照 / 视频 / 慢动作 / 延时 / 移动延时 / 直播 / 超级夜景 / 人物跟踪 / 360 系列模式等），且选中项会随相机实际模式自动同步。
- **拍录控制**：大圆钮完成拍照、开始 / 停止录制，按下带触感反馈，录制中按钮变绿。
- 支持按机型自动适配可切换的模式列表（Action 系列、Osmo 360、未知机型兜底）。

### 4. GPS 推送

- 利用手机融合定位（GPS + 基站 + WiFi）获取位置。
- 连接相机后自动以 10Hz 将经纬度、速度、海拔推送到相机，使录制的视频带上地理信息。
- 设置页可实时查看定位结果（经纬度 / 速度 / 海拔），并手动开关推送。

### 5. 个性化

- 界面语言：中文 / English，运行时一键切换。
- 主题：默认（Material You）/ 大疆暗色。

---

## 支持设备

- Osmo Action 5 Pro（已完成全部功能测试，其他设备只完成了逻辑验证）
- Osmo Action 4 / Action 3
- Osmo 360
- 未知机型（列出全部模式，便于实机探测）

---

## 使用方式

应用底部三个标签页：

1. **扫描**：下拉刷新搜相机 → 点 `Connect` 连接。
2. **操控**：查看相机状态、切换模式、按拍录大圆钮拍摄。
3. **设置**：切换语言 / 主题，查看并开关 GPS 推送。
